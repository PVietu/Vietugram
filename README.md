# ✦ Vietugram — Мессенджер нового поколения

**Разработчик:** Vietu  
**Версия:** 4.0  
**Стек:** Python (Flask + Socket.IO + Eventlet) + HTML/CSS/JavaScript (чистый фронтенд)

---

## 📖 Описание проекта

Vietugram — это веб-приложение реального времени для текстового и голосового общения. Поддерживает:

- 💬 Текстовые и 🎙️ голосовые чат-комнаты (WebRTC)
- 🎨 Гибкую систему ролей с кастомными ролями
- 🛡️ Модерацию: кик, бан, удаление сообщений
- 📌 Закрепление сообщений и 📢 объявления
- 🤖 API для ботов
- 🐍 Встраивание Python-кода через Pyodide
- 🏆 Таблицу лидеров в реальном времени
- 👥 Систему друзей и личных сообщений
- 💾 Постоянное хранение всех данных на диске

## 🔐 Система ролей и прав

| Роль | Иконка | Цвет | Описание |
|------|--------|------|----------|
| Пользователь | 👤 | Белый | Базовая роль при регистрации |
| Ветеран | 🏆 | Голубой | Автоматически после 1000 сообщений |
| Модератор | 🛡️ | Зелёный | Назначается администратором |
| Администратор | 👑 | Красный | Вход через код в Админ-панели |
| Владелец комнаты | 🏠 | Фиолетовый | Создатель конкретной комнаты |
| Кастомная роль | 🎨 | Любой | Создаётся модератором / администратором |

### Права ролей

**👤 Пользователь:**
- Создание комнат, отправка сообщений, прикрепление изображений
- Редактирование и удаление своих сообщений
- Использование тегов, упоминаний, реакций
- Вход в открытые и защищённые паролем комнаты

**🛡️ Модератор (+ всё, что пользователь):**
- Удаление любых сообщений и комнат
- Кик пользователей из комнат
- Создание объявлений
- Ограничение частоты сообщений
- Закрепление комнат в списке
- Создание, изменение и удаление кастомных ролей
- Назначение кастомных ролей пользователям

**👑 Администратор (+ всё, что модератор):**
- Вход в любые комнаты без пароля (включая скрытые)
- Бан / разбан пользователей
- Назначение / снятие модераторов
- Доступ к Админ-панели
- Режим наблюдателя (невидимость)
- Глобальные объявления и сообщения при входе
- Просмотр лога действий

**🏠 Владелец комнаты (в пределах своей комнаты):**
- Удаление комнаты
- Закрепление сообщений
- Кик участников
- Передача прав другому пользователю
- Установка ограничений частоты сообщений

### Получение роли Администратора

- Реальный голосовой чат через браузер (без плагинов)

- Трансляция экрана с плавающим окном
- Одновременная трансляция нескольких участников

### Типы комнат

| Тип | Иконка | Описание |
|-----|--------|----------|
| Обычная | 💬 | Текстовый чат |

| Защищённая | 🔒 | Вход по паролю |

| Временная | ⏳ | Удаляется после истечения времени |

## 💾 Резервное копирование

### Автоматическое (каждый час)

Сервер автоматически создаёт резервные копии в папку `backups/auto_ДАТА/`.

### Ручное резервное копирование

Просто скопируйте папку `data/`:

```bash
cp -r data/ backups/manual_$(date +%Y%m%d_%H%M%S)/
```

### Через API (только для администраторов)

```bash
curl -X POST http://localhost:5000/api/backup \
  -H "X-Admin-Token: ВАШ_ТОКЕН"
```

### Восстановление

```bash
# Остановите сервер
# Скопируйте нужный бэкап в data/
cp -r backups/auto_20241201_120000/ data/
# Запустите сервер
python server.py
```

## 🤖 Bot API — Туториал по созданию бота

### Установка зависимостей

```bash
pip install requests
```

### Минимальный пример бота

```python
import requests
import time

SERVER = "http://localhost:5000"   # или ваш IP
BOT_TOKEN = "my_secret_token_123"  # минимум 8 символов
BOT_NAME = "MyBot"

# 1. Подключить бота (создаёт комнату)
def connect():
    r = requests.post(f"{SERVER}/api/bot/connect", json={
        "token": BOT_TOKEN,
        "bot_name": BOT_NAME,
        "room_name": f"🤖 {BOT_NAME}",
    })
    data = r.json()
    print(f"✅ Бот подключён! Комната: {data['room_id']}")
    return data["room_id"]

# 2. Отправить сообщение
def send(room_id, text):
    requests.post(f"{SERVER}/api/bot/send", json={
        "token": BOT_TOKEN,
        "room_id": room_id,
        "text": text,
    })

# 3. Получить новые сообщения
def get_messages(room_id, since=0):
    r = requests.get(f"{SERVER}/api/bot/messages", params={
        "token": BOT_TOKEN,
        "room_id": room_id,
        "since": since,
    })
    return r.json().get("messages", [])

# 4. Основной цикл
def main():
    room_id = connect()
    send(room_id, "👋 Бот запущен!")

    last_ts = 0
    while True:
        messages = get_messages(room_id, since=last_ts)
        for msg in messages:
            text = msg.get("text", "")
            author = msg.get("author", "?")
            last_ts = max(last_ts, msg.get("ts", 0))

            print(f"[{author}]: {text}")

            if "привет" in text.lower():
                send(room_id, f"Привет, {author}! 👋")

            if text.strip() == "/help":
                send(room_id, "📋 Команды:\n/help — помощь\n/time — время")

            if text.strip() == "/time":
                from datetime import datetime
                send(room_id, f"🕐 {datetime.now().strftime('%H:%M:%S')}")

        time.sleep(1)

if __name__ == "__main__":
    main()
```

### API Эндпоинты бота

| Метод | URL | Описание |
|-------|-----|----------|
| POST | `/api/bot/connect` | Подключить бота |
| POST | `/api/bot/send` | Отправить сообщение |
| GET | `/api/bot/messages` | Получить новые сообщения |
| GET | `/api/rooms` | Список комнат |

## 🐍 Python Мини-приложение — Туториал

В Vietugram есть встроенный редактор Python-кода, выполняемого через **Pyodide (WebAssembly)** прямо в браузере.

### Открытие редактора

Нажмите кнопку **🐍 Код** в верхней панели.

### Доступный API

```python
# Объект vietugram предоставляет:

# Отправить сообщение в текущую комнату
vietugram.send_message("Привет из Python!")

# Получить название текущей комнаты
room = vietugram.get_room()
print(f"Текущая комната: {room}")

# Получить ваш ник
me = vietugram.get_username()
print(f"Меня зовут: {me}")
```

### Примеры скриптов

**Пример 1: Hello World**
```python
name = vietugram.get_username()
room = vietugram.get_room()
vietugram.send_message(f"👋 Привет от {name} из Python! Комната: {room}")
print("Готово!")
```

**Пример 2: Математический бот**
```python
import math

result = math.sqrt(144)
vietugram.send_message(f"√144 = {result}")

primes = [n for n in range(2, 50) if all(n % i != 0 for i in range(2, n))]
vietugram.send_message(f"Простые числа до 50: {primes}")
```

**Пример 3: Данные из сети (Pyodide поддерживает fetch)**
```python
import js
import asyncio

async def fetch_joke():
    response = await js.fetch("https://v2.jokeapi.dev/joke/Any?type=single&lang=ru")
    data = await response.json()
    joke = data.joke if hasattr(data, 'joke') else "Нет шутки 😢"
    vietugram.send_message(f"😄 {joke}")

asyncio.ensure_future(fetch_joke())
```

### Сохранение скриптов

Скрипты сохраняются в **localStorage** браузера. Нажмите **💾 Сохранить**, введите название — скрипт появится в выпадающем списке.

## 🐛 Решение проблем

**Микрофон не работает:**
- Для локального запуска: `http://localhost` (без SSL) — работает
- Для публичного сервера нужен HTTPS (Let's Encrypt + nginx)

**Нет соединения:**
- Убедитесь, что `server.py` запущен
- Проверьте, что порт открыт в firewall: `ufw allow 5000`
- Проверьте логи: `tail -f logs/server.log`

**Потеря данных при рестарте:**
- Все данные хранятся в `data/` — папка сохраняется при перезапуске
- При корректном завершении (Ctrl+C) данные сохраняются автоматически
