## 📦 Установка и запуск

### Требования

```bash
pip install flask flask-socketio eventlet
```

### Локальный запуск (ваш компьютер)

```bash
python server.py
```

Откройте браузер: `http://localhost:5000`

### Запуск на сервере с белым IP

1. Загрузите файлы `server.py` и `index.html` на сервер в одну папку
2. Убедитесь, что порт **5000** открыт в firewall
3. Запустите:

```bash
python server.py
```

4. Пользователи заходят по адресу: `http://ВАШ_IP:5000`

### Запуск в Google Colab

```python
# Установка зависимостей
!pip install flask flask-socketio eventlet pyngrok -q

# Запуск сервера в фоне + туннель ngrok
from pyngrok import ngrok
import subprocess, threading

def run_server():
    subprocess.run(['python', 'server.py'])

t = threading.Thread(target=run_server)
t.daemon = True
t.start()

import time; time.sleep(2)

# Открыть публичный туннель
public_url = ngrok.connect(5000)
print(f'🌐 Vietugram доступен по адресу: {public_url}')
```

## 🔐 Система ролей

| Роль | Иконка | Цвет | Описание |
|------|--------|------|----------|
| Пользователь | 👤 | Белый | Базовая роль при регистрации |

### Получение администратора

1. Зайдите в аккаунт
2. Нажмите кнопку **⚙️ Админ** в верхней панели
3. Введите секретный код (нигде публично не публикуется)
4. Теперь у вас роль Администратора

### Права ролей

**👤 Пользователь:**
- Создание комнат, отправка сообщений
- Прикрепление изображений
- Реакции на сообщения
- Упоминания @username

**🛡️ Модератор:**
- Всё, что пользователь +
- Удаление комнат
- Кик пользователей из комнат
- Удаление сообщений
- Отправка объявлений в комнатах
- Особый цвет ника (жёлтый) и префикс [MOD]
- Создание кастомных ролей
- Назначение кастомных ролей пользователям

**👑 Администратор:**
- Всё, что модератор +
- Вход в комнаты без пароля
- Бан/разбан пользователей
- Назначение/снятие модераторов
- Доступ к Админ панели
- Режим Наблюдателя (невидим в комнатах)
- Кастомное сообщение входа в комнату
- Глобальные объявления для всех
- Особый цвет ника (красный) и префикс [ADMIN]

### 🏠 Владелец комнаты

Тот, кто создал комнату, получает права:
- Удаление своей комнаты
- Закрепление сообщений

## 💬 Функции чата

### Текстовые комнаты
- Отправка текстовых сообщений
- Прикрепление изображений (кнопка 📷 или Drag & Drop)
- **Shift+Enter** — перенос строки, **Enter** — отправка
- Упоминания: `@username` — пользователь получит уведомление
- Теги сообщений: `#важное`, `#срочно`, `#todo`
- Реакции на сообщения (😊 → выбрать эмодзи)
- Редактирование своих сообщений (кнопка ✏️)
- Поиск сообщений по автору (кнопка 🔍)
- Закрепление сообщений (📌, только модераторы/владельцы)

### Голосовые комнаты (WebRTC)
- Реальный голосовой чат через браузер
- Визуальный индикатор активности речи (зелёная рамка)
- Кнопки управления: 🎙️ Микрофон, 🔊 Звук, 📺 Трансляция экрана
- Трансляция экрана с отдельным окном просмотра
- Регулировка громкости отдельных участников (ползунок)
- Настройки микрофона: выбор устройства, громкость, шумоподавление
- Индикатор заглушенного микрофона 🔇

### Типы комнат
| Тип | Описание |
|-----|----------|
| 💬 Обычная | Текстовый чат |
| 🎙️ Голосовая | WebRTC голосовой чат |
| 🔒 Защищённая | Вход только по паролю |
| 🥷 Анонимная | Все ники скрыты |
| ⏳ Временная | Самоуничтожается через N секунд |
| 🐌 Со спам-защитой | Задержка между сообщениями |
| 🤖 Бот-комната | Созданная через Bot API |

2. В поле "Назначить роль" введите ник пользователя
3. Выберите роль из списка

## 🤖 Bot API (Интеграция ботов на Python)

Vietugram поддерживает подключение ботов через HTTP API.  
При подключении бота автоматически создаётся отдельная комната.

### Туториал: создание бота на Python

#### Установка

```bash
pip install requests
```

#### Минимальный пример бота

```python
import requests
import time

# Конфигурация
SERVER = "http://localhost:5000"  # или ваш IP/домен
BOT_TOKEN = "my_secret_bot_token_123"  # придумайте свой токен (мин. 8 символов)
BOT_NAME = "MyBot"

# 1. Подключение бота
def connect_bot():
    resp = requests.post(f"{SERVER}/api/bot/connect", json={
        "token": BOT_TOKEN,
        "bot_name": BOT_NAME,
        "room_name": f"🤖 {BOT_NAME}"  # название комнаты
    })
    data = resp.json()
    print(f"✅ Бот подключён! Комната: {data['room_id']}")
    return data["room_id"]

# 2. Отправка сообщения
def send_message(room_id, text):
    resp = requests.post(f"{SERVER}/api/bot/send", json={
        "token": BOT_TOKEN,
        "room_id": room_id,
        "text": text
    })
    return resp.json()

# 3. Получение новых сообщений
def get_messages(room_id, since=0):
    resp = requests.get(f"{SERVER}/api/bot/messages", params={
        "token": BOT_TOKEN,
        "room_id": room_id,
        "since": since
    })
    return resp.json().get("messages", [])

# 4. Основной цикл бота
def main():
    room_id = connect_bot()
    send_message(room_id, "👋 Бот запущен и готов к работе!")
    
    last_ts = 0
    while True:
        messages = get_messages(room_id, since=last_ts)
        for msg in messages:
            text = msg.get("text", "")
            author = msg.get("author", "?")
            print(f"[{author}]: {text}")
            last_ts = max(last_ts, msg.get("ts", 0))
            
            # Пример: отвечать на "привет"
            if "привет" in text.lower():
                send_message(room_id, f"Привет, {author}! 👋")
            
            # Пример: команда /help
            if text.strip() == "/help":
                send_message(room_id, "📋 Доступные команды:\n/help — помощь\n/time — текущее время")
            
            # Пример: команда /time
            if text.strip() == "/time":
                from datetime import datetime
                send_message(room_id, f"🕐 Текущее время: {datetime.now().strftime('%H:%M:%S')}")
        
        time.sleep(1)  # пауза 1 секунда

if __name__ == "__main__":
    main()
```

### API Endpoints

| Метод | URL | Описание |
|-------|-----|----------|
| POST | `/api/bot/connect` | Подключить бота (создаёт комнату) |
| POST | `/api/bot/send` | Отправить сообщение |
| GET | `/api/bot/messages` | Получить новые сообщения |
| GET | `/api/rooms` | Список всех комнат |

#### POST /api/bot/connect
```json
{
  "token": "ваш_секретный_токен_минимум_8_символов",
  "bot_name": "НазваниеБота",
  "room_name": "🤖 Моя Бот-Комната"
}
```
**Ответ:**
```json
{
  "room_id": "abc123",
  "bot_username": "BOT_НазваниеБота",
  "status": "connected"
}
```

#### POST /api/bot/send
```json
{
  "token": "ваш_токен",
  "room_id": "abc123",
  "text": "Текст сообщения"
}
```

#### GET /api/bot/messages?token=...&room_id=...&since=0
```json
{
  "messages": [
    {
      "id": "msg_id",
      "author": "username",
      "text": "текст",
      "ts": 1700000000000
    }
  ]
}
```

### Пример продвинутого бота (эхо-бот с командами)

```python
import requests
import time
from datetime import datetime

SERVER = "http://localhost:5000"
TOKEN = "my_advanced_bot_2024"
BOT_NAME = "EchoBot"

def main():
    # Подключение
    r = requests.post(f"{SERVER}/api/bot/connect", json={
        "token": TOKEN, "bot_name": BOT_NAME,
        "room_name": "🤖 Echo Bot"
    })
    room_id = r.json()["room_id"]
    
    send = lambda t: requests.post(f"{SERVER}/api/bot/send",
        json={"token": TOKEN, "room_id": room_id, "text": t})
    
    send("🤖 EchoBot запущен! Команды: /help, /time, /echo [текст]")
    
    last_ts = 0
    COMMANDS = {
        "/help": lambda a,t: "📋 Команды:\n/help — помощь\n/time — время\n/echo [текст] — эхо",
        "/time": lambda a,t: f"🕐 Сейчас: {datetime.now().strftime('%d.%m.%Y %H:%M:%S')}",
    }
    
    while True:
        msgs = requests.get(f"{SERVER}/api/bot/messages",
            params={"token": TOKEN, "room_id": room_id, "since": last_ts}
        ).json().get("messages", [])
        
        for m in msgs:
            text = m.get("text", "").strip()
            author = m.get("author", "Аноним")
            last_ts = max(last_ts, m.get("ts", 0))
            
            if text.startswith("/echo "):
                send(f"🔊 {text[6:]}")
            elif text in COMMANDS:
                send(COMMANDS[text](author, text))
        
        time.sleep(0.5)

if __name__ == "__main__":
    main()
```

## 🐍 Python Мини-приложение (встраивание в браузер)

В интерфейсе Vietugram есть кнопка **🐍 Мини-приложение**, которая открывает всплывающее окно для встраивания Python кода бота.

### Как использовать

1. Нажмите кнопку **🐍 Мини-приложение** в верхней панели
2. В открывшемся окне вставьте код вашего бота
3. Нажмите **📋 Копировать** для копирования кода в буфер обмена
4. Запустите скопированный код в вашем Python окружении

### Шаблон кода для запуска локально


## 🐛 Решение проблем

### Микрофон не работает в голосовом чате
- Откройте сайт по `https://` (нужен SSL для WebRTC в публичных сетях)
- Для локальной разработки `http://localhost` работает без SSL
- Разрешите доступ к микрофону в браузере

### Нет соединения с сервером
- Убедитесь, что `server.py` запущен
- Проверьте, что порт 5000 не занят другим приложением
- Проверьте firewall

### Сообщения не отображаются
- Обновите страницу
- Проверьте консоль браузера (F12) на ошибки
